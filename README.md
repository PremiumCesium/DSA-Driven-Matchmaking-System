Purpose: This is a video game - based program that groups 100,000 queued players and matches groups of 12 of them into matches by their matchmaking rating. This program compares the speeds of two structures, the Red - Black Tree structure and the B+ Tree structure.

The Project must be ran from the main project folder not src or data.

When using the menu, select through the options in the order they are listed in. Options 2 and 3 will not work unless the data is initialized ( option 1), Options 5 and 6 will not work without 2,3 and 4 being done first. It cannot compare insert times if nothing was inserted likewise with matchmaking.

If order is not followed an error message will occur.

When complete entering 7 will exit the program.
